# QuizManagementSystem
Quiz &amp; Exam Management System is a Java-based application that allows users to attempt quizzes, manage questions, and automatically calculate exam results. It uses Java OOP concepts, collections, and basic input handling to provide a simple and efficient examination system.

A simple Java-based Quiz and Exam Management System made as a semester project.

The main purpose of this project is to provide a basic system where users can attempt quizzes, answer multiple-choice questions, and get their results automatically. It also allows new questions to be added to the quiz.

## Features

* Start and attempt a quiz
* Multiple-choice questions
* Automatic score calculation
* Percentage calculation
* Pass/Fail result
* Add new questions
* View available questions
* Simple menu-based interface

## Technologies Used

* Java
* Object-Oriented Programming (OOP)
* ArrayList
* Arrays
* Scanner
* Java Collections

## How to Run

1. Install Java JDK on your computer.
2. Clone this repository.
3. Open the project in IntelliJ IDEA, Eclipse, or any Java-supported IDE.
4. Compile and run `QuizManagementSystem.java`.
5. Select an option from the menu and start using the system.

## How It Works

When the program starts, a menu is displayed with different options. The user can start the quiz, view the available questions, or add a new question.

After completing the quiz, the system calculates the number of correct and incorrect answers and displays the final percentage along with the result.
